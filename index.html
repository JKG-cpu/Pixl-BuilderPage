GitHub Repo CLI Tool

A command-line tool written in Python for exploring GitHub repositories without leaving the terminal.

  • Configure settings, including a GitHub auth token
  • Fetch repository info - description, language, visibility, stars, forks, and license
  • Read a repository's README.md
  • Browse repository contents (files and folders)
  • View commit history and commit messages
