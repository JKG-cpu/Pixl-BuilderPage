I created the portfolio for the [Pixl Hackathon](https://pixl.hackclub.com/en).

There is a static site that was deployed. There you can see one of my projects (OctoTrack) and how you can contact me!

The static site is deployed [here](https://jkg-cpu.github.io/Pixl-BuilderPage/).

The website is pretty simple, so feel free to take any of the HTML or CSS Code. Also it would be great if you could go over to my [OctoTrack Repository](https://github.com/JKG-cpu/OctoTrack) and view that project as well!

## What is in this website?

I included 3 of my top projects so far:
- OctoTrack
- PyNoteCLI
- Framex-Studio

For each of these spaces, I included basically what the features are, like what is already included / built on the project.

## Running Locally

You can clone the GitHub repo like this
```bash
git clone https://github.com/JKG-cpu/Pixl-BuilderPage
```

Then just open `index.html` in your browser and you can see the website for yourself and change anything you want!
